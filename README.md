# Project 01: Messy Data to Manager Report

**Tools:** Microsoft Excel | Power Query | PivotTables | Data Analysis

**Status:** In Progress

## 1. Project Overview

This project demonstrates how to transform a messy business dataset into a clean, organized, and meaningful management report.

The objective is to take raw operational data, identify data-quality problems, clean and organize the information, analyze business performance, and communicate findings to management.

## 2. Business Scenario

Imagine you are an Operations Analyst working for a company that manages inventory and product shipments.

Management wants to understand:
- Which products have the highest inventory movement?
- Are there inventory discrepancies?
- Which products are experiencing delays?
- What operational trends require management attention?

You have been given an unorganized dataset and must turn it into useful business information.

## 3. Project Objectives

1. Import and inspect raw business data.
2. Identify missing values, duplicates, and inconsistent records.
3. Clean and organize the dataset.
4. Use Excel formulas to analyze the information.
5. Create PivotTables to summarize performance.
6. Build a management dashboard.
7. Present findings and recommendations.
